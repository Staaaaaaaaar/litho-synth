# LithoSynth

LithoSynth 是面向多岩石多样性研究的合成场景、数据生成与分析工具。

项目当前以 BlenderProc 为首个后端，优先建立一个简单、可控且可重复的多岩石场景闭环。后续将根据研究需要逐步扩展地形、岩石、材质和其他合成数据后端。

## 当前范围

- 多岩石场景构建与渲染
- RGB、深度、实例标注和已知属性导出
- 基于已知属性的场景与数据集多样性分析
- 基础检查与可视化

感知、视觉表征、采样决策和机器人仿真不属于当前实现范围。

## 项目状态

项目处于初始化阶段，尚未提供可运行的生成流程。当前方案见 [docs/plan/v1.0.md](docs/plan/v1.0.md)。

## 近期目标

1. 建立 BlenderProc 运行骨架；
2. 生成平坦地形与随机多岩石场景；
3. 导出基础渲染结果和已知岩石属性；
4. 加入基础检查与可视化。

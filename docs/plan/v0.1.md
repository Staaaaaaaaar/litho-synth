# LithoSynth v0.1 Plan

## 1. 基本信息

- 项目版本：v0.1
- 状态：进行中
- 更新日期：2026-08-28

## 2. 阶段目标

基于 BlenderProc 建立 LithoSynth 的最小可运行闭环，能够可重复地构建和渲染简单多岩石场景，并导出基础数据与已知岩石属性。

## 3. 交付内容

- LithoSynth 基础工程与运行入口；
- 平坦地形和随机多岩石场景；
- 基础相机、光照和可复现随机配置；
- RGB、深度、实例标注和已知岩石属性导出；
- 基础数据检查与可视化。

## 4. 技术决策

- 使用 BlenderProc 作为当前场景构建、渲染和标注后端；
- 必要时使用 `bpy` 补充 BlenderProc 未封装的场景操作；
- v0.1 只实现单后端，不迁移其他合成数据项目；
- 暂不固定最终数据结构、岩石属性体系和多样性算法。

## 5. 里程碑与验收条件

### M1：工程骨架

验收：能够通过统一入口加载配置并启动最小流程。

### M2：场景渲染

验收：能够使用固定随机种子重复生成平坦地形、多块岩石及 RGB 图像。

### M3：数据导出

验收：能够导出深度、实例标注和对应的已知岩石属性。

### M4：检查与可视化

验收：能够检查基础输出完整性，并可视化场景、标注和岩石属性。
